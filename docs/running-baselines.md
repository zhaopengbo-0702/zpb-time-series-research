# 模型运行说明

[模型目录](model-catalog.md) · [按分类浏览模型](../models/) · [实现与版本说明](upstream-sources.md)

先从模型介绍了解原理，再选择实验方式。DLinear、TSMixer 与三个朴素对照方法已接入[统一实验入口](integration.md)，共用配置、数据划分、指标和结果比较；完整命令与实测结果见[合成示例](../examples/forecasting/README.md)。

其他实现可从模型页后半部分的“实现”和“运行方式”进入完整源码入口。下文说明如何准备独立环境、数据与训练命令。

## 1. 找到选定实现的工作目录

从[模型目录](model-catalog.md)进入模型页，记录模型名和实现编号，再打开该实现列出的核心模型、运行入口和工作目录。

终端中的当前目录会影响相对导入、数据路径、提示文本、配置文件和检查点位置。运行前切换到模型页明确指出的工作目录。模型展示目录用于介绍与导航；它不必是训练脚本实际读取文件的工作目录。

若页面的入口是使用文档或 Notebook，先在本地打开该实现保留的原始说明，按其示例构造数据与模型。不要将某个实现的 `run.py`、参数名或数据路径直接套给另一个实现。

## 2. 为该实现准备独立环境

| 项目 | 需要确认的内容 |
| --- | --- |
| Python | 依赖文件或包配置声明的版本范围 |
| 计算框架 | 所需张量计算与训练框架版本；CPU/GPU 包、驱动与计算精度是否匹配 |
| 依赖声明 | 当前实现中的 `requirements.txt`、`pyproject.toml` 或环境配置；模型所需的可选依赖 |
| 安装方式 | 脚本项目与可安装 Python 包的用法不同；要运行收录版本，应确认导入的是当前源码或对应固定版本 |
| 本地记录 | 实际安装版本、设备、精度和环境导出文件，便于复做实验 |

不同实现可能对 Python、数值库和训练框架提出冲突的版本要求，应分别建环境，不要将全部依赖合并安装。Windows 下的 `.sh` 脚本需要 Bash 环境；涉及 Linux 编译扩展、分布式训练或特定 GPU 算子的实现，要按其实际支持条件配置。

## 3. 准备数据与外部权重

按选定实现的数据入口确认时间列、目标列、变量顺序、序列标识、历史窗口和预测长度。数据文件放在运行参数指定的位置；相对路径按实际工作目录解释。多个实现共用一份数据时，可以分别配置数据根目录，同时保留一致的数据文件版本。

模型源码、外部数据与预训练权重分别管理。数据下载接口或模型加载接口出现在源码中，并不意味着相应数据、tokenizer 或权重已包含在仓库。需要预训练资源的模型应先确认权重版本、访问条件、缓存位置、磁盘占用与运行内存，再执行加载。

归一化和特征构造应符合实验划分，训练统计量不能使用测试集。已知未来协变量必须在真实预测时可获得，不能把未来目标误当作已知输入。

## 4. 按实际入口启动

| 页面列出的入口形式 | 如何继续 |
| --- | --- |
| 命令行脚本 | 查看参数解析和对应示例脚本，填写数据位置、模型配置及输出目录 |
| Python API | 按示例构造数据对象、模型和训练器，再调用训练与预测接口 |
| Notebook | 在该实现的环境中检查数据准备和训练单元，逐步执行并记录实际参数 |
| 分布式启动器 | 同步核查进程数、设备映射、混合精度与配置文件；仅修改启动参数不一定同步修改内部配置 |
| 预训练预测接口 | 确认权重和数据格式，区分零样本推理、微调与从头训练 |

第一次运行可先选择较小的数据片段、批量和训练预算，核对数据维度、损失、预测输出与保存位置，再进行完整实验。脚本可能连续执行多组实验，也可能包含清理检查点的代码；长时间运行前先在本地查看入口末尾及其调用函数，确认结果按自己的需要保存。

工作区已提供[统一实验入口](integration.md)，支持下文所列的已接入模型。其他实现可按各自环境运行，实验配置与结果仍可沿用同一记录标准。

## 5. 让不同模型的结果可以比较

| 对齐项 | 应固定或报告的内容 |
| --- | --- |
| 数据 | 文件版本、时间划分、缺失值处理、列顺序、目标与协变量 |
| 任务 | 输入窗、预测长、输出变量、采样频率；适用时记录解码器历史长度 |
| 预处理 | 归一化拟合范围、特征构造、是否反归一化 |
| 指标 | 具体实现、计算尺度、跨样本和变量的聚合规则 |
| 训练 | 优化器、学习率、训练预算、早停、调参范围与验证规则 |
| 随机性 | 各随机数来源的种子、重复次数、均值和波动；固定种子本身不保证完全确定性 |
| 资源 | 设备、精度、峰值显存、计时边界；适用时报告预训练来源与微调范围 |
| 版本 | 模型名、实现编号、锁定提交、个人修改、完整命令或调用代码 |

相似的参数名不保证相同语义，相同模型名也不保证不同实现输出尺度一致。先核对数据到指标的完整链路，再比较预测效果、速度与资源消耗。原始版本与文件范围见[实现与版本说明](upstream-sources.md)，源码阅读顺序见[模型阅读路线](model-guide.md)。
