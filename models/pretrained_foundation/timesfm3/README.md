# TimesFM3

调用 TimesFM 3.0 预训练模型，与早期版本分开索引。

**类别：** 预训练时序模型

[返回分类目录](../../../docs/model-catalog.md#category-pretrained_foundation)

## 这是什么

TimesFM3 是 TimesFM 3.0 的版本特定适配，明确包含多变量上下文与协变量处理。它与早期版本应分开评估。

## 核心思路

模型通过 patch 和变量间注意力共同处理多个目标通道。过去协变量作为仅历史通道，未来协变量作为历史及未来可见通道，并结合归一化和分位数预测。

## 适用问题

适合具有多变量目标和已知未来特征的零样本预测，或与早期独立分量预测版本比较。

## 局限与边界

目标与协变量总通道数受权重 max_variates 限制，窗口和预测长度也受配置约束。未来协变量必须真实可知，不能把未来目标伪装成输入特征。

## 阅读建议

先看权重配置中的 max_variates，再检查 target、past 与 future 三类通道的 mask 和拼接，最后核对预测时保留哪些目标通道。
