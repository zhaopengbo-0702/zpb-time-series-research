# TiRex

调用 tirex-ts 的预训练模型，为零样本预测提供接口。

**类别：** 预训练时序模型

[返回分类目录](../../../docs/model-catalog.md#category-pretrained_foundation)

## 这是什么

TiRex 入口调用预训练的时序模型预测未来。它保留简单零样本包装和另一份较完整适配，方便按同一个方法家族查找。

## 核心思路

简单包装加载 NX-AI/TiRex，对各变量调用 forecast，接收分位数与点预测，再组织输出。完整适配还管理权重、输入窗口和可选训练配置。

## 适用问题

适合预训练时序模型的零样本预测比较，也可研究分位数输出与点预测的使用差异。

## 局限与边界

简单包装逐变量预测，未直接利用跨变量联合关系。不同适配暴露的能力不同，需要外部权重、依赖和足够的运行资源。

## 阅读建议

先分清调用的是简单包装还是完整适配，再核对 forecast 的两个返回值和分位数设置，避免把分布输出丢失过程忽略。
