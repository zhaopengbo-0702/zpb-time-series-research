# TiRex2

调用 TiRex-2，支持多变量及过去、未来协变量预测。

**类别：** 预训练时序模型

[返回分类目录](../../../docs/model-catalog.md#category-pretrained_foundation)

## 这是什么

TiRex2 是面向第二代权重的预测适配，支持多个目标一起预测，也允许过去和未来协变量参与条件化。

## 核心思路

适配器构造目标与协变量输入，调用 TiRex-2 的联合预测接口，并按预训练分位数处理输出和微调损失。可选择冻结、部分微调或全量微调。

## 适用问题

适合多变量概率预测、协变量增益分析及第二代预训练模型的微调比较。

## 局限与边界

预测长度加输出移位不能超过权重允许的最大范围；微调要保留预训练分位数的损失约定。外部权重与依赖需要另外取得。

## 阅读建议

先读目标和协变量的形状注释，再核对输出移位与最大预测长度检查，最后区分训练全分位数和推理选择分位数。
