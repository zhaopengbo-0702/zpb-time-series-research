# Moirai

调用 uni2ts 的预训练 Moirai 模型，接口用于零样本预测。

**类别：** 预训练时序模型

[返回分类目录](../../../docs/model-catalog.md#category-pretrained_foundation)

## 这是什么

Moirai 入口把历史交给已有的通用时序预测模型。本次简单包装实际使用 Moirai 2.0 的小型权重，而名称仍保留为系列名。

## 核心思路

实现构建 Moirai2Forecast，设置历史长度与预测长度，逐变量传入历史并汇总输出。当前包装将目标维度设为 1，动态协变量维度设为 0。

## 适用问题

适合零样本预测对照和 Moirai 系列迁移表现观察，尤其是先不修改模型结构的评估。

## 局限与边界

这里的包装没有暴露模型可能具备的全部多变量或协变量能力；输出汇总也会压缩分布信息。系列论文与当前权重版本需要分别记录。

## 阅读建议

先核对 moirai-2.0-R-small 权重和 target_dim，再看逐变量循环。阅读论文时把通用模型能力与本包装器实际开放的输入区分开。

## 阅读材料

[相关论文](https://arxiv.org/pdf/2402.02592)

链接为上游 README 列出的 Moirai 系列论文；当前接口实际加载 moirai-2.0-R-small，具体版本以源码和权重标识为准。
