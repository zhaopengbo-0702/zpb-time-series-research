# TimeMoE

调用预训练 TimeMoE 混合专家时序模型，入口用于零样本预测。

**类别：** 预训练时序模型

[返回分类目录](../../../docs/model-catalog.md#category-pretrained_foundation)

## 这是什么

TimeMoE 使用预训练的混合专家时序模型，让不同专家分担输入模式。这里收录的简单接口主要把历史送入已有权重进行预测。

## 核心思路

适配代码加载 TimeMoE-50M，按要求整理数值上下文并调用生成过程，再恢复预测区间。专家选择和主要序列建模发生在外部模型内部。

## 适用问题

适合比较混合专家预训练模型的零样本预测能力，以及观察不同领域数据上的迁移差异。

## 局限与边界

混合专家并不代表总模型没有显存成本；外部权重和运行实现都要准备。简单入口没有提供完整的专家训练或自定义路由实验能力。

## 阅读建议

先记录实际加载的 50M 权重，再核对上下文归一化、生成长度和输出截取；要研究专家行为时需进一步进入模型实现。
