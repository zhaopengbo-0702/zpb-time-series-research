# ARIMA

通过自回归、差分和移动平均描述时间依赖。

**类别：** 统计与朴素基线

[返回分类目录](../../../docs/model-catalog.md#category-statistical)

## 这是什么

先用差分去掉一部分趋势，再用过去的值和过去的预测误差解释下一步。它把时序关系写成较明确的统计结构，便于判断哪些依赖可以由线性动态描述。

## 核心思路

参数 p 控制自回归项，d 控制差分次数，q 控制移动平均误差项；拟合后递推未来值，必要时还接入外生变量。当前接口具体支持哪些季节和概率选项，要看构造参数与底层拟合调用。

## 适用问题

适合单条或少量序列上的统计对照，也适合检查趋势处理后是否还存在稳定的线性时间依赖。样本量不大、希望解释阶数和残差结构时，通常容易形成可检查的分析流程。

## 局限与边界

阶数选择不当、结构突变和强非线性都会影响结果；差分过多还会损失有用信息。较高阶模型需要更多历史，外生变量在预测区间内是否真实可获得也必须确认。

## 阅读建议

沿构造参数、fit 和 predict 看阶数怎样传入，再检查趋势项、外生特征和预测区间。比较不同实现时同时记录差分、季节设置、是否重新拟合和输出的尺度。
