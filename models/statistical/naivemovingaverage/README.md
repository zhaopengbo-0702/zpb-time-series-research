# NaiveMovingAverage

利用末段窗口的移动平均递推预测。

**类别：** 统计与朴素基线

[返回分类目录](../../../docs/model-catalog.md#category-statistical)

## 这是什么

用最近一段观测的平均值表示当前水平，希望比单个最后值更平滑，又比整个历史均值更及时。窗口长度决定它重视多长的近期变化。

## 核心思路

从最后一个窗口计算均值生成下一步，再把预测值追加到窗口中继续递推，直到达到预测长度。实际实现是否递归更新，必须看其预测循环而不是只凭名称判断。

## 适用问题

适合噪声较大但水平变化较慢的简单对照，也适合研究近期窗口比全历史更有用的情况。应对不同窗口长度使用一致的验证规则。

## 局限与边界

平均会滞后于快速变化，趋势和周期也可能被抹平；多步递推会逐渐使用模型自己的常数化输出。窗口太短易追噪声，太长则失去及时性。

## 阅读建议

重点读 input_chunk_length、均值计算和预测更新循环。记录窗口到底包含真实观测还是已生成预测，并检查短历史或窗口不足时是报错、截断还是采用其他规则。
