# AutoTBATS

自动选择含三角季节项、趋势等成分的 TBATS 配置。

**类别：** 统计与朴素基线

[返回分类目录](../../../docs/model-catalog.md#category-statistical)

## 这是什么

当周期不止一个、周期较长或季节形状复杂时，用三角函数状态表示周期变化，并自动选择其余统计结构。它属于自动统计建模，不是注意力网络。

## 核心思路

从允许的变换、趋势、阻尼、ARMA 误差和三角季节表示中选择 TBATS 配置，再拟合状态并预测。自动搜索如何裁剪候选、支持哪些季节周期，需要依据当前实现参数确认。

## 适用问题

适合把多季节或长季节结构纳入传统预测对照，例如同时存在日内和周内周期的序列。使用前仍要确认采样规则以及周期对应的观测点数量。

## 局限与边界

多周期与较高状态维度可能提高训练成本；短数据很难稳定识别长周期。自动搜索无法保证找到全局最优，也不会自动补齐缺失时间或解释节假日变化。

## 阅读建议

先核对季节周期列表、变换和误差模型开关，再看选型与拟合结果。务必把 AutoTBATS 与固定 TBATS 的搜索预算区分，不能只比较最后一次预测调用耗时。
