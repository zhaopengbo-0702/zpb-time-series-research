# AutoTheta

自动配置 Theta 方法，预测并组合分解后的成分。

**类别：** 统计与朴素基线

[返回分类目录](../../../docs/model-catalog.md#category-statistical)

## 这是什么

Theta 方法把序列转换成不同趋势或曲率的视图，再组合预测；AutoTheta 进一步自动挑选这些设置。可以把它理解为对几种简洁统计描述的有规则筛选。

## 核心思路

在允许的 Theta 结构和季节处理选项中拟合候选，用实现规定的准则选择模型，然后对趋势与平滑成分预测并重组。它的搜索选项与手工指定 Theta 参数的实现并不完全一样。

## 适用问题

适合单变量统计基线和批量预测任务，尤其适合检验简洁的趋势加平滑能达到什么水平。与其他方法对比时，输入长度和季节周期应采用相同的数据依据。

## 局限与边界

突变、强外生冲击和复杂变量关系并非其主要建模对象。自动选型对短历史较敏感，季节调整错误也会把原本有规律的部分处理坏。

## 阅读建议

从构造参数查看候选 Theta 模型和季节配置，再检查最终选择与输出还原。记录是固定拟合后滚动预测，还是测试期间持续重新选型，两者使用的信息量不同。
