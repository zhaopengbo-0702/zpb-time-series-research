# MultiInceptionTimePlus

以多个 InceptionTimePlus 分支处理输入组并融合输出。

**类别：** 集成与校准

[返回分类目录](../../../docs/model-catalog.md#category-ensemble_calibration)

## 这是什么

当一个样本有多组输入时，不必把它们立即混在一起，而是给每组输入一个卷积分支，再把表示合并。这里的 Multi 表示多分支结构，并不等于多个独立模型最终投票。

## 核心思路

按配置把通道或输入划分到多个 InceptionTimePlus 分支，各分支提取多尺度卷积表示，随后拼接或经共同输出头形成任务结果。输入拆分与分支配置决定实际模型结构。

## 适用问题

适合多组传感器、不同变量子集或希望保持分组处理的分类与回归任务。可用于比较“先各组提特征再融合”和“先合并所有通道”两种设计。

## 局限与边界

分组不合理可能切断有用关系，分支越多也不保证信息更多；共享或独立参数、输入长度与头部形状都需检查。它不是一个有固定效果保证的通用集成算法。

## 阅读建议

先读输入 splitter 的索引，再看每个分支是否去掉原任务头，以及最终融合头怎样连接。对照实验应控制总参数和输入信息，避免仅靠增加分支或特征获得不公平优势。
