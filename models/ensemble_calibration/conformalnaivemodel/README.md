# ConformalNaiveModel

对基础预测历史误差做保形校准，调整区间覆盖目标。

**类别：** 集成与校准

[返回分类目录](../../../docs/model-catalog.md#category-ensemble_calibration)

## 这是什么

先用已有预测器给出点预测，再根据它在过去犯过多大的错，给当前预测加上合适宽度的区间。它是预测区间的校准层，不是替代基础预测器的新网络。

## 核心思路

在每个预测起点之前提取校准历史，产生回测误差和非一致性分数，根据目标分位数调整区间边界。对称和非对称设置会改变上下界是否使用相同的误差修正。

## 适用问题

适合希望给点预测增加可检查不确定性区间的任务。应同时报告实际覆盖率、平均区间宽度以及分预测跨度表现，而不只看点预测误差。

## 局限与边界

序列依赖、分布漂移和校准样本不足会影响覆盖表现；保形方法的条件与实际滚动序列设置需要匹配。区间变宽也不意味着基础预测更准确。

## 阅读建议

先找已拟合的基础 model，再查 cal_length、cal_stride、quantiles 和校准起点。确保校准误差来自当时不可见目标的真实回测，不能把未来测试误差提前拿来调区间。
