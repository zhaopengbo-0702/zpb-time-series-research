# TST

使用时序嵌入和编码器注意力构建序列分类或回归。

**类别：** Transformer与注意力

[返回分类目录](../../../docs/model-catalog.md#category-transformer_attention)

## 这是什么

TST 是用 Transformer 编码时间序列的分类或回归网络。它把多通道观测转换为按时间排列的表示，学习不同时间位置间的联系。

## 核心思路

输入投影后加入位置表示，经过多层注意力和前馈网络，再由头部汇聚为目标输出。mask 与序列长度设置影响可见范围。

## 适用问题

适合传感器、波形等多变量序列的分类和序列级回归，也可作为卷积网络的注意力对照。

## 局限与边界

基础接口的输出任务由头部决定，并非默认多步预测器。长窗口的全注意力开销、缺失值处理和 padding mask 都要检查。

## 阅读建议

先核对输入通道与时间轴，再看投影、位置编码、mask 和头部顺序，记录序列长度是否固定。
