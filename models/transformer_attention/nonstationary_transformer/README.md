# Nonstationary_Transformer

在归一化输入之外学习去平稳注意力因子，补回序列的非平稳信息。

**类别：** Transformer与注意力

[返回分类目录](../../../docs/model-catalog.md#category-transformer_attention)

## 这是什么

这个模型试图同时得到归一化带来的稳定训练，以及原序列均值、波动变化中包含的信息。可以理解为先把数据尺度整理好，再把被整理掉的重要变化补给注意力。

## 核心思路

序列平稳化用于规范输入与恢复输出。额外的投影网络从原始序列及统计量学习去平稳因子，对注意力分数进行缩放和偏移。

## 适用问题

适合研究均值、方差随时间变化的预测任务，以及比较普通归一化与可学习去平稳调节。

## 局限与边界

可学习因子本身需要训练数据，不能保证适应所有分布漂移。归一化统计量的计算范围必须遵守时间划分，避免使用未来信息。

## 阅读建议

先追踪输入标准化和输出反标准化，再看 tau、delta 的产生与传递位置，最后对照普通注意力去掉这些因子的消融。
