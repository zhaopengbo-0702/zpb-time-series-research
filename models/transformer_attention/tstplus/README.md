# TSTPlus

使用时序嵌入和编码器注意力构建序列分类或回归。 此项为 的 Plus 可配置变体。

**类别：** Transformer与注意力

[返回分类目录](../../../docs/model-catalog.md#category-transformer_attention)

## 这是什么

TSTPlus 是 TST 思路的可配置实现变体，方便更换注意力、归一化或输出头。它的研究价值在于比较这些结构选择。

## 核心思路

模型仍以时间序列嵌入和 Transformer 编码为主，提供更多结构开关与头部配置。具体与基础 TST 的差别应以构造参数和 forward 为准。

## 适用问题

适合序列分类、回归和受控结构消融，例如比较残差注意力、层数或头部设置。

## 局限与边界

Plus 表示实现变体，不能直接推断一定优于基础模型。不同配置的参数量和正则强度可能同时变化，需要逐项对照。

## 阅读建议

先按接近基础 TST 的设置阅读，再比较额外开关对模块和输出形状的影响；引用基础方法时注明使用的是配置变体。
