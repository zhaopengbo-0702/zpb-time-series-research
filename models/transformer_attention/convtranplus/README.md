# ConvTranPlus

结合卷积嵌入、时序绝对位置和相对位置注意力。

**类别：** Transformer与注意力

[返回分类目录](../../../docs/model-catalog.md#category-transformer_attention)

## 这是什么

ConvTranPlus 先用卷积提取局部时序与通道特征，再让注意力关联较远的位置。它的一个重点是为时序设计绝对和相对位置表示。

## 核心思路

两阶段二维卷积先沿时间再融合通道，之后加入可选 tAPE 等绝对编码，并使用 eRPE 等相对位置注意力。编码结果经池化或自定义头输出。

## 适用问题

适合多变量序列分类或序列级回归，尤其是同时包含局部波形和较长位置关系的任务。

## 局限与边界

默认头部并非通用多步预测器，预测任务要明确设计输出形状。位置编码与输入长度绑定，改变长度时需要检查相关参数。

## 阅读建议

先读两层卷积如何改变张量形状，再对照 abs_pos_encode、rel_pos_encode 的分支，最后看默认池化头与自定义头的区别。
