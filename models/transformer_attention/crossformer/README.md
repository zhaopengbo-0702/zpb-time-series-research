# Crossformer

把每个变量的序列切成片段，用分层和两阶段注意力处理时间与变量关系。

**类别：** Transformer与注意力

[返回分类目录](../../../docs/model-catalog.md#category-transformer_attention)

## 这是什么

Crossformer 同时关心一条变量随时间怎么变，以及不同变量之间怎么联系。它先把各变量分成时间片段，再分开处理这两类关系。

## 核心思路

分段嵌入形成时间与变量两个维度的 token。两阶段注意力分别建模时间依赖和跨变量交互，层次化合并逐步扩大时间尺度，解码过程汇聚多尺度信息。

## 适用问题

适合变量间耦合较强的多变量预测，以及研究时间交互与跨变量交互是否应分别建模。

## 局限与边界

分段长度会改变局部细节和 token 数；变量很多时，跨变量模块仍有成本。输入长度和变量数相关的构造参数需要与数据一致。

## 阅读建议

先确认 DSW 嵌入后的张量形状，再读两阶段注意力中的时间阶段和维度阶段，最后检查相邻层如何合并片段。
