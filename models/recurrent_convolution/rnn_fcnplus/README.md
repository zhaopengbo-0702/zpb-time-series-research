# RNN_FCNPlus

融合 RNN 循环分支与全卷积分支的序列网络。 此项保留 Plus 配置扩展。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

RNN_FCNPlus 同时走两条路：普通循环单元提取顺序表示，全卷积支路寻找局部波形。两路最后合并，尝试让状态记忆与局部形状提供互补信息。

## 核心思路

循环分支使用当前输入与上一步隐藏状态，经线性变换和非线性激活得到新状态并取最后输出；卷积分支经过多层卷积和全局池化，两者拼接后映射到目标。Plus 将骨干与头部分开，支持自定义和多维输出。

## 适用问题

适合同时依赖局部波形与较整体表示的序列分类或回归。可分别移除循环或卷积分支，确认组合效果是否确实来自互补信息。

## 局限与边界

特别要核对 shuffle：默认配置可能把变量轴当作循环步，完整时间窗成为每步特征，不能仍解释为逐时间循环。两分支组合也增加容量，需公平控制。

## 阅读建议

先确认 RNN 分支的实际输入形状与 shuffle，再看卷积分支的池化维度和拼接宽度。继续读 head 的 d 与 custom_head 设置，确认输出轴。
