# GRU

以更新门和重置门递推隐藏状态，学习序列信息。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

GRU 把一段序列逐步读入同一个门控循环单元，用一个随输入更新的状态概括过去。它的核心问题是当前观察应该怎样改变记忆，再把记忆转成任务需要的输出。

## 核心思路

通过更新门与重置门控制旧状态和新候选状态的组合。收录实现既有取最后状态接线性头的序列级模型，也有编码历史后接预测头的版本；模型页中的具体实现决定输出形式。

## 适用问题

适合做顺序信息建模的基础对照，例如片段分类、回归或历史到未来的映射；也便于研究窗口长度、状态宽度与单双向处理的影响。

## 局限与边界

门控结构仍需按顺序更新，隐藏宽度和窗口长度影响信息压缩及计算成本。双向配置只能使用已经可见的输入窗口，不能直接把未来目标送入状态。

## 阅读建议

先从所选实现的输入转置读起，确认GRU沿时间还是其他轴更新，再看取最后状态、全序列表示或解码器的路径，并核对损失与输出形状。
