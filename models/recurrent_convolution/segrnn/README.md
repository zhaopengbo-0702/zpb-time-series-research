# SegRNN

将序列分段后交给 GRU 编码，再按预测片段输出未来值。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

SegRNN 不让循环网络逐个读入每一个数，而是先把连续一小段压成一个向量。循环网络读完这些片段后，再利用位置与变量信息生成未来的多个片段。

## 核心思路

实现将每个通道减去末值后分段，线性嵌入送入 GRU 得到历史状态；预测端把未来片段的位置嵌入和通道嵌入拼接，结合历史状态还原片段，最后加回末值。

## 适用问题

适合研究分段表示如何减少循环步数，以及直接生成预测片段是否比逐点递推更适合较长预测窗口；也便于做片段长度消融。

## 局限与边界

输入与预测长度需要满足分段整形要求，片段过长可能抹平局部细节。通道嵌入表示变量身份，但不应直接解释为已显式建模所有变量间交互。

## 阅读建议

重点查看 seg_len、reshape、位置和通道嵌入的广播方式。沿着批量与通道合并后的维度读 GRU，再确认最后还原预测顺序并加回末值的位置。
