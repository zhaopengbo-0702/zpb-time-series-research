# DilatedRNN

以不同时间跨度的循环连接捕捉长期依赖。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

DilatedRNN 让循环状态可以跨着时间走。某些层读取相邻位置，另一些层隔几步更新状态，以多种时间间隔连接历史，减少长距离信息必须逐点传递的路径。

## 核心思路

实现按 dilation 对序列重排并组织多个循环分支，可配置不同循环单元和层组，提取跨尺度状态后通过解码头输出预测；膨胀循环与膨胀卷积的计算机制不同。

## 适用问题

适合研究短期依赖与较慢变化并存的预测问题，也适合比较增加循环深度和改变时间跳步两种扩大历史联系的方式。

## 局限与边界

跳步结构可能降低局部细节的直接联系，dilation 需要结合窗口和预测尺度选择。不同循环单元、残差配置和解码头会改变参数量，不能只对比名称。

## 阅读建议

从 DRNN 的重排与恢复顺序读起，用短序列画出不同 dilation 下哪些位置共享循环状态，再看层组如何汇总状态并送入最终预测头。
