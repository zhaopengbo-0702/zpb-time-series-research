# XceptionTimePlus

将深度可分离卷积与多尺度时序模块结合。 此项为 的 Plus 可配置变体。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

XceptionTimePlus 在可分离的多尺度残差卷积上提供更多可配置组件，使骨干与输出设置可以按任务调整，而非只沿用固定的末端结构。

## 核心思路

实现将 Xception 模块、残差块与任务头分层，支持坐标输入、归一化、可分离卷积等配置，头部使用自适应汇总及逐点变换；实际参数决定启用哪些机制。

## 适用问题

适合对可分离多尺度卷积做消融，或研究不同汇总与输出设计如何影响序列级分类和回归。

## 局限与边界

Plus 变体不保证比基础结构更好，多项可选设置会改变容量和归纳偏置。输入长度变化、自适应池化和类别头之间的关系也应验证。

## 阅读建议

从构造参数开始核对 backbone 与 head 的边界，再读残差通道投影。比较基础版时，分别固定核宽、通道数、池化长度和增强开关。
