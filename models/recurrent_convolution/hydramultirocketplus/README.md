# HydraMultiRocketPlus

融合 Hydra 竞争卷积和 MultiRocket 统计特征。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

这个模型把两种不同的随机卷积特征放在一起：一类统计核之间的竞争，另一类统计响应的比例、强度和持续方式，希望提供互补的序列描述。

## 核心思路

实现并行构建 Hydra 与 MultiRocket 特征骨干，将它们的输出拼接，再通过可配置头映射到目标。原序列、差分与多种膨胀率参与特征提取。

## 适用问题

适合评估特征组合能否帮助序列分类或回归，也便于分别移除两个分支，判断收益来自哪类统计。

## 局限与边界

拼接特征会增加存储和头部输入维度，分支互补需要实验验证。参数与初始化可能影响高维表示，不能将组合名称直接当成效果提升的证据。

## 阅读建议

先核对两个子骨干各自产生多少特征，再看拼接、归一化和输出头。阅读拟合过程时确认哪些阈值来自训练集，并记录随机种子与特征预算。
