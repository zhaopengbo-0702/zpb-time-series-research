# LSTMPlus

LSTM 的 可配置骨干与任务头变体。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

LSTMPlus 保留长短期记忆单元的基本记忆方式，同时将骨干与任务头拆开。它更像一套可配置的循环模型组件，方便按数据类型与目标输出调整接口。

## 核心思路

骨干中利用输入门、遗忘门和输出门更新细胞状态与隐藏状态，并支持类别嵌入、可选前端特征提取、不同隐藏宽度和双向层；头部可以取末步或展平全序列，并接归一化、dropout 或自定义映射。

## 适用问题

适合需要混合输入特征或替换输出头的分类和回归，也适合固定循环骨干后单独检验头部、前端提取器和读出方式的影响。

## 局限与边界

Plus 不表示所有增强都默认启用。展平读出依赖序列长度，可能显著增加参数；类别嵌入和双向配置也需要符合预测时可获得的信息。

## 阅读建议

先读 _RNN_Backbone 的特征输入，再对照 LSTMPlus 选定的循环单元，最后检查 last_step、custom_head 与隐藏维数；把骨干变化和读出变化分开记录。
