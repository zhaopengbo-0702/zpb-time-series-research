# FCN

用多层一维卷积和全局池化提取序列特征。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

FCN 用几层一维卷积寻找局部波形，再把整段序列汇总成一个表示。它不依赖循环状态，主要通过卷积检测哪些形状在序列中出现。

## 核心思路

结构依次堆叠卷积、归一化与激活，经过全局平均池化压缩时间轴，最后线性映射到类别或回归目标；输出通常是整段序列的一个向量。

## 适用问题

适合序列分类、片段级回归和卷积基线实验，特别适合观察局部形状是否已足够区分类别。

## 局限与边界

全局平均池化会弱化事件发生的精确位置，有限卷积感受野也会限制远距离组合。现成的分类头不能直接等同于多步预测头。

## 阅读建议

先看卷积核和通道数，再确认池化前后形状与输出损失。若要做预测，需要明确构造未来时间轴，而不是只把类别数改成预测长度后忽略任务语义。
