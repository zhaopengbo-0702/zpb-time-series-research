# LSTMAttention

结合 LSTM 循环表示和注意力编码模块的序列网络。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

LSTMAttention 先用长短期记忆单元生成每个位置的表示，再让这些位置通过注意力互相查询。它希望同时使用顺序记忆与较直接的跨位置联系。

## 核心思路

循环部分利用输入门、遗忘门和输出门更新细胞状态与隐藏状态，保留完整位置输出；之后送入多头自注意力、前馈与残差归一化编码器，再展平或经自定义头输出序列级目标。

## 适用问题

适合完整窗口的分类与回归，也适合分析加入跨位置注意力后，是否弥补仅取循环末状态造成的信息压缩。

## 局限与边界

注意力增加随窗口长度增长的成本，整个窗口的双向联系也不等于逐时刻因果计算。长序列展平头会增加参数，效果需与相同容量基线比较。

## 阅读建议

先看 LSTM 是否返回全部时间步，再追踪注意力的查询、键和值来自哪里；核对头数、隐藏维度与输出展平长度，避免把注意力权重直接当成因果解释。
