# MultiRocketPlus

联合原序列与差分序列的多种卷积池化统计特征。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

MultiRocketPlus 不只问卷积响应超过阈值的比例，还描述正响应有多大、持续多长、出现在什么位置，并把原始变化和差分变化一起观察。

## 核心思路

实现对原序列与一阶差分应用多膨胀率卷积，在响应上计算多种池化统计，如正值均值和最长正值区间等，最后拼接特征并交给可训练输出头。

## 适用问题

适合形状、变化速度和模式持续性都可能重要的序列分类或回归，也适合逐项移除池化统计以分析信息来源。

## 局限与边界

特征数量会随统计种类增加，内存与头部正则化需要关注。统计池化仍是压缩表示，对复杂事件顺序的保留有限；差分也可能放大噪声。

## 阅读建议

先看原序列和 diff 分支，再逐个阅读池化函数的数学含义。检查阈值如何拟合、无正响应时如何处理，以及最终特征维数与头部输入是否一致。
