# ResNetPlus

通过残差一维卷积堆叠提取时间序列特征。 此项为 的 Plus 可配置变体。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

ResNetPlus 让一维残差网络的组件和输出头更加可配置。核心仍是卷积提取变化并通过捷径保留信息，但可以按任务开启额外机制。

## 核心思路

实现提供残差卷积骨干，支持可分离卷积、坐标输入、通道重标定或注意力等参数，再接可配置池化、dropout 和输出范围；不同开关对应不同网络。

## 适用问题

适合在残差基线上逐项做结构消融，也适合需要调整输出头的分类与回归任务。

## 局限与边界

Plus 名称不能替代完整配置，多项开关同时改变会让结果难以归因。注意力或通道加权的收益需要实验验证，固定长度头也可能显著改变参数量。

## 阅读建议

先读 ResBlockPlus 的参数与跳接，再追到主类的头部构造。记录 sa、se、coord、separable 与池化设置，分别对照关闭这些选项的版本。
