# ResNet

通过残差一维卷积堆叠提取时间序列特征。

**类别：** 循环与卷积

[返回分类目录](../../../docs/model-catalog.md#category-recurrent_convolution)

## 这是什么

ResNet 把卷积学到的变化与输入捷径相加，使每个模块更像在修正已有表示。对时序数据，它通过堆叠一维残差卷积来识别局部形状及其组合。

## 核心思路

模型由多个残差块组成，每块包含卷积、归一化与激活，通道不匹配时使用投影捷径，最后对时间轴汇总并映射到目标输出。

## 适用问题

适合序列分类和片段回归，也适合与无残差 FCN 比较，检验残差设计在相同数据和预算下是否有帮助。

## 局限与边界

残差连接并不自动解决所有长距离依赖，实际范围仍受卷积结构限制。全局池化会压缩位置，网络深度与通道数增加也可能带来额外过拟合。

## 阅读建议

从每个残差块的主路和捷径读起，核对相加前形状，再看最终池化与分类头。先画出块数、核宽和通道变化，比较时不要只报层数。
