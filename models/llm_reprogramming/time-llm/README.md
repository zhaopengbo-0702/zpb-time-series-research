# Time-LLM

把时序 patch 对齐到文本原型，并用提示词与冻结语言模型生成预测表示。

**类别：** LLM重编程

[返回分类目录](../../../docs/model-catalog.md#category-llm_reprogramming)

## 这是什么

Time-LLM 尝试让已有语言模型处理数值序列，而不是从头训练一个大型时序主干。它先把时序片段翻译成语言模型能够接收的表示。

## 核心思路

时序 patch 经过重编程层对齐到文本原型表示，并与任务说明、序列统计等提示组合输入冻结的语言模型。后续预测头从隐藏表示输出未来数值，可训练部分主要集中在映射与预测模块。

## 适用问题

适合研究预训练语言模型能否迁移到时间序列，以及提示信息、重编程层和冻结主干各自的作用。

## 局限与边界

需要单独获取语言模型权重与对应运行环境；冻结主干仍有显存和推理成本。提示与序列统计必须只用可见历史，不能将未来信息写入提示。

## 阅读建议

先核对语言模型是否冻结，再读 patch 到文本原型的重编程注意力和提示构造，最后检查预测头及训练参数列表。
