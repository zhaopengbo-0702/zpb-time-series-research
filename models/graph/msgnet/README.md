# MSGNet

先发现不同周期尺度，再通过图卷积和注意力学习多变量之间的关系。

**类别：** 图结构

[返回分类目录](../../../docs/model-catalog.md#category-graph)

## 这是什么

MSGNet 认为变量间的关系可能在不同时间尺度上不同。它先找出若干主要周期，再在这些尺度上学习变量之间怎样传递信息。

## 核心思路

实现利用傅里叶分析选取周期，构建多尺度表示，通过图卷积和注意力模块进行变量交互，再融合各尺度结果形成预测或任务输出。

## 适用问题

适合具有多种周期、变量相互影响的多变量序列，或研究固定通道关系是否过于简单。

## 局限与边界

周期选择和图结构从数据估计，噪声、短窗口或周期漂移会影响结果。学习到的图反映模型关联，不能直接认定为真实因果网络。

## 阅读建议

先看 FFT_for_Period 的周期选择，再追踪各尺度 GraphBlock 的输入轴与输出合并，检查 top_k 与窗口长度。
