# Koopa

分离不同变化成分，用可学习和动态估计的 Koopman 算子推进隐状态。

**类别：** 状态空间动力学

[返回分类目录](../../../docs/model-catalog.md#category-state_space_dynamics)

## 这是什么

Koopa 试图把复杂变化转到一个更容易推进的隐空间。在这个空间里，未来状态可以近似由线性算子一步步推出。

## 核心思路

实现先按频谱分离不同变化成分，通过编码器形成隐状态，对不同成分使用可学习或由当前窗口估计的 Koopman 算子，再解码未来。动态算子使用最小二乘等步骤估计。

## 适用问题

适合研究非平稳预测、动态系统表示与可更新状态转移，并比较固定算子和窗口自适应算子。

## 局限与边界

隐空间线性近似是否成立依赖数据与编码器。最小二乘可能病态，长步递推会累积误差；当前任务路径主要针对长期预测。

## 阅读建议

先读 FourierFilter 的成分划分，再看 KPLayer 如何从相邻状态估计算子，最后检查多步推进及重构误差。
