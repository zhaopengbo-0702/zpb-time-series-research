# RMoK

通过路由组合多种 KAN 专家，利用不同函数基预测。

**类别：** 线性与MLP

[返回分类目录](../../../docs/model-catalog.md#category-linear_mlp)

## 这是什么

准备多种 KAN 专家，再让路由器按输入决定各专家贡献多少。直观上，它希望不同函数形式分工处理不同的时序模式。

## 核心思路

实现包含多种函数展开的专家，例如小波、Taylor 和 Jacobi 类型，并通过路由权重混合输出；同时结合多变量序列的输入组织和归一化。

## 适用问题

适合研究异质模式、专家分工及可学习路由，尤其适合在相同输入下比较单个专家、平均混合与训练路由的差别。

## 局限与边界

专家可能学成相似映射，路由也可能偏向少数专家；数量增加会带来参数和优化成本。路由权重体现计算分配，并不能直接当作变量因果解释。

## 阅读建议

先逐个确认专家的基函数形式，再看路由归一化、混合位置和通道维度。消融时保持总参数或训练预算接近，记录专家实际使用情况。
