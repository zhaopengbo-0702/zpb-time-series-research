# DeepNPTS

学习历史观测的权重，以非参数方式形成预测分布。

**类别：** 线性与MLP

[返回分类目录](../../../docs/model-catalog.md#category-linear_mlp)

## 这是什么

不直接预测一个任意的新数，而是学习历史观测值应得到多大权重，再将这些值加权组合成未来预测。它源于加权经验分布的思路；当前收录实现输出的是点预测。

## 核心思路

网络根据历史窗口和可用特征，为各预测步生成历史位置权重，沿历史轴做 softmax，再与历史目标逐项相乘求和。因此每个预测值是当前窗口历史观测的非负归一化加权平均。

## 适用问题

适合作为基于历史取值重组的点预测对照，也适合研究跨相关序列学习的权重能否优于均匀权重、末值或直接 MLP 映射。

## 局限与边界

当前实现明确只支持点损失，forward 没有提供经验分布抽样或分位数输出。预测是历史观测的凸组合，直接外推到当前窗口最小值和最大值以外的能力受到限制。

## 阅读建议

先核对构造函数的点损失检查，再追踪 softmax 的历史轴及最终求和。不要把原方法的概率解释直接当成当前接口已实现的概率预测功能。
