# MLP

将历史窗口或表格变量交给多层前馈网络，作为非线性对照。

**类别：** 线性与MLP

[返回分类目录](../../../docs/model-catalog.md#category-linear_mlp)

## 这是什么

把最近一段观测当作一组普通输入特征，交给多层全连接网络学习预测或判别规则。它提供一个容易理解的非线性参照，帮助判断专门的时序结构是否有额外价值。

## 核心思路

历史窗口与所选特征经过若干线性变换和激活函数，再由输出层给出目标。窗口展开方式、隐藏宽度、协变量连接和输出头由具体实现决定。

## 适用问题

适合固定长度窗口、结构化特征已经比较充分的任务，以及卷积、循环或注意力模型的对照。研究时可逐项增加层数、宽度和输入特征，观察收益来自哪里。

## 局限与边界

模型不会自动获得平移等变性或长期递推记忆。直接展开长窗口可能增加参数，换采样频率或窗口长度通常需要重配输入层；小数据下也容易过拟合。

## 阅读建议

从一条样本如何变成输入向量开始，核对最后一层输出表示分类、回归还是多步预测。先建立简单窄网络，再增加复杂度，避免只比较参数量差异。
