# KAN

用可学习的一元函数替代普通 MLP 边权拟合非线性关系。

**类别：** 线性与MLP

[返回分类目录](../../../docs/model-catalog.md#category-linear_mlp)

## 这是什么

普通 MLP 主要学习连接的权重，KAN 则让连接上的一元函数也可以学习。它希望用更灵活的函数组合来表达输入与目标之间的非线性关系。

## 核心思路

将输入分量送入可学习的基函数或函数展开，再组合成下一层表示。具体采用样条还是其他展开必须查看实现，不能把所有 KAN 视作相同网络。

## 适用问题

适合研究小型非线性映射、函数参数化方式，以及在固定预测流程中替换 MLP 的影响。可以比较基函数数量、网格或阶数与预测表现的关系。

## 局限与边界

表示定理不保证有限样本训练就能达到理想效果，也不保证更快、更小或自动可解释。函数展开的分辨率、正则化和输入尺度会影响稳定性与外推。

## 阅读建议

先看一层如何把每个输入映射为函数值，再检查层间组合与预测头。评价时同时报告参数量、计算开销和种子波动，而不仅看一次误差。
