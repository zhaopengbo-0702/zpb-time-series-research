# MultiTSTPlus

对输入组分别应用 TSTPlus，再融合表示的封装。

**类别：** 通用模型适配器

[返回分类目录](../../../docs/model-catalog.md#category-model_adapter)

## 这是什么

把变量分成几组，让每组先独立经过一个时序 Transformer，再合并表示。它是一种多分支封装，适合保留输入分组结构，而不是一个独立提出的全新注意力公式。

## 核心思路

按配置索引拆分输入通道，为各组建立 TSTPlus 分支，获取分支特征并接共同任务头。分组方式、是否共享参数以及每个分支的配置决定实际网络规模。

## 适用问题

适合具有明确变量组或多个输入来源的分类、回归任务，可检验分组编码是否优于把所有通道一次性混合。也便于复用已有的注意力骨干。

## 局限与边界

独立分支可能延迟甚至削弱跨组关系，组数增加还会扩大参数和内存需求。它不自动保证各组样本时间对齐，也不会替你确定合理的变量划分。

## 阅读建议

先找 splitter、各组索引和分支构造，再看原输出头是否移除及共同头怎样连接。公平比较时控制总参数、输入信息和训练预算，而不能只让多分支版本看到更多变量。
