# SKLearnClassifierModel

将 scikit-learn 分类器接入序列预测。

**类别：** 通用模型适配器

[返回分类目录](../../../docs/model-catalog.md#category-model_adapter)

## 这是什么

把通用分类器用于离散目标的序列预测，提供统一的窗口、标签和输出接口。它并不把任意分类器自动升级为擅长所有时间任务的专用模型。

## 核心思路

按滞后规则提取监督特征，将未来目标整理为类别标签，调用传入分类器拟合，再把类别或概率还原到时序输出。类别编码、多目标和预测跨度由外层组织。

## 适用问题

适合离散状态、事件类别和具有明确分类目标的时序任务，也可作为不同通用分类器的共同实验入口。连续值预测需要另选回归接口或明确定义离散化任务。

## 局限与边界

分类器支持的标签类型、概率方法和多输出能力并不一致；时间相邻样本随机划分还可能泄漏信息。接口不能替你决定阈值、类别权重和概率校准。

## 阅读建议

从真实 classifier、classes 映射和 lag 构造读起，再检查 predict 与 predict_proba 的分支。保留标签定义和训练区间，分类指标不要与连续回归误差混在一个排名中。
