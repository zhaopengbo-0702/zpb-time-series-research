# FFT

在去趋势等处理后选择傅里叶成分并外推周期变化。

**类别：** 分解平滑频域

[返回分类目录](../../../docs/model-catalog.md#category-decomposition_frequency)

## 这是什么

用若干周期波形的叠加解释历史，再把这些波形向未来延伸。这是一种频谱外推的统计方法，名字中的 FFT 是计算 Fourier 变换的工具。

## 核心思路

实现可先处理趋势，再从 Fourier 表示选取频率或系数，利用保留成分重建并延伸周期部分，最后按配置加回趋势。它不等同于带 FFT 层的神经网络。

## 适用问题

适合稳定周期信号、频域分析和无需深度训练的基础对照，也适合检查主要频率是否足以解释预测任务。

## 局限与边界

未来频率与相位变化、突发事件和不稳定趋势会破坏周期外推；有限窗口会产生频谱泄漏。保留太多频率可能同时外推噪声。

## 阅读建议

先画历史频谱与保留的频率，再单独检查趋势的拟合和外推。核对窗口边界、周期对齐与频率筛选规则，避免只根据重建效果判断预测能力。
