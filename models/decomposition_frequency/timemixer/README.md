# TimeMixer

将序列分为多个尺度和趋势季节成分，通过 MLP 混合并汇总多尺度预测。

**类别：** 分解平滑频域

[返回分类目录](../../../docs/model-catalog.md#category-decomposition_frequency)

## 这是什么

同时用粗细不同的时间尺度看历史，让快变化和慢变化分别交流，再汇总多尺度预测。直观上是把一条曲线变成几种分辨率后分工处理。

## 核心思路

下采样构造多尺度输入，分解趋势和季节成分，通过前馈混合在尺度之间传递信息，再由多尺度预测模块组合未来输出。

## 适用问题

适合多尺度趋势和周期共存的预测，也适合研究不同采样分辨率的互补性。可以比较尺度数、下采样形式、分解方法与混合方向。

## 局限与边界

下采样会丢失部分高频信息，尺度设置与实际周期不匹配时可能无益。多分支预测也会增加配置空间，不能仅凭更复杂的结构断言效果更好。

## 阅读建议

先列出每个尺度的时间长度，再看趋势和季节分支沿什么方向跨尺度传递。最后确认各尺度预测如何对齐相加，并核对归一化路径。
