# 改进模型

每个独立版本建立一个目录，例如 `ema_phase_v1/`、`pyra_multiscale_v1/`。目录中保存代码和 `README.md`，后者包括：

1. 基于哪个模型、哪个上游提交，以及本仓库的代码提交。
2. 改动的模块、要检验的假设和基线版本。
3. 训练入口、环境名、数据路径和完整运行命令。
4. 对应的实验编号与结果链接。

跨目录导入时明确项目根路径；各上游都有可能使用 `models`、`layers` 或 `utils` 等同名包，运行适配应避免互相遮蔽。

已有原版改进沿用对应独立项目的入口；需要在同一任务流程下比较多个模型时，可先阅读 [`../../libraries/Time-Series-Library/`](../../libraries/Time-Series-Library/) 的实验类和模型接口，再建立自己的适配版本。记录改进基于独立原版还是 TSLib 内实现，具体对应关系见[模型索引](../../docs/model-catalog.md)。

这里目前仅建立研究目录，尚未添加个人改进算法。
